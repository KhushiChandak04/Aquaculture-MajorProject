## 🔄 Workflow for Colab Users (Shravya & Janhavi)

1. **Download** `final_dataset.csv` from `data/processed/` in this repo
2. **Upload** it to your Colab notebook
3. **Train** your model in Colab
4. **Save** model & metrics:
   ```python
   import joblib
   joblib.dump(model, "sustainability_model.pkl")  # or feature_selector.pkl
   metrics_df.to_csv("sustainability_metrics.csv", index=False)
   ```
5. **Download** the `.pkl` and `.csv` files from Colab
6. **Upload** them to the correct folders in this GitHub repo:
   - `.pkl` → `models/`
   - `.csv` → `results/`

> **No Google Drive syncing. No auto linking. Just upload to GitHub. Simple.**

## 🔗 How Final Merging Works

Once all 3 models exist in `models/`:

```python
import joblib

productivity_model   = joblib.load("models/productivity_model.pkl")
sustainability_model = joblib.load("models/sustainability_model.pkl")
feature_selector     = joblib.load("models/feature_selector.pkl")
```

The Streamlit app then:
1. Takes user input
2. Applies `feature_selector` for genomic features
3. Predicts productivity (regression)
4. Predicts sustainability (classification)
5. Shows SHAP explanations
